🍵 茶包出库（优先用散装）×

逐行填药材与每包需求量（克）。做多包时点「份数」自动按倍数扣料；提交后先扣散装、不足再扣整装，跨批次补足。

📋 茶包配方模板×

在「茶包出库」里填好每行后点「存为配方」即可保存；此处可载入或删除。
勾选多个配方可一起合并出库；也可点单条「单独载入」。

📥 批量录入×

支持「无日期」「保质期N年/月」「整装/散装」。可加「批号:XXX」给供应商批号。多行一次录入，自动按名称+批次拆分。

⚙ 提醒设置×

本机「💾 保存」可下载 JSON 备份；「☁ 云端」走 Dxy-Sync 自动同步（推荐）。

☁ 云端同步（Dxy-Sync）×

已配置 Token 时，打开页面自动从云端拉取最新；编辑后点「⬆ 保存到云端」推送。Token 与内容工作台同一把。

🏦 药房借看板（欠款核销）×

负库存 = 从药房借入的克重。下方按药材汇总「累计借入 / 已还 / 当前欠款」；点「回补冲抵」入库可自动冲抵欠款。

🛒 采购清单（消耗累计·自动补货）×

按出库流水累计各药材消耗，低于补货阈值的自动列入采购。

📋 盘点（盘盈/盘亏）×

系统按现有库存 diff，自动生成盘盈(+)/盘亏(-)调整记录，计入同步流水。

⚙ 别名 / 按个换算配置×

出库按克计算时自动换算并展示个数（如 1 个≈18克）。保存后随云端同步。
