☁️ 数据同步设置 手机/电脑互通

开启后，所有录入数据（任务看板、灵感备忘、数据复盘、我的选题）实时存到你的 GitHub 私有仓库。手机和电脑打开同一个分享链接，数据自动一致。Token 仅保存在本机浏览器，不上传他人。

保存后自动上云（每次点「确认保存」都会同步）；换设备前点「保存到云端」，新设备打开本网址会自动用云端最新版覆盖本机。手机/电脑通用。
⚠️ 你正在用 file:// 打开，浏览器可能拦截 GitHub 同步（CORS）。请改用手机/电脑通用的云链接打开本工作台，同步才稳定。
首次使用三步：① 连接 GitHub ② 新建一个私有仓库 ③ 生成 Token（经典令牌勾 repo 权限最省事）。详细步骤见随附《数据互通使用说明》。停用后仅本机保存。
